# chizu 要件定義

chizu は、2D で遊ぶ都市建設シミュレーターである。道路・鉄道・住宅・産業・生活インフラを整え、街に住む人の幸福度を上げていく。見た目は図形と色だけにとどめ、計算資源はシミュレーションに回す。

## 方針

- 描画より計算を優先する。グラフィックは状態が読み取れれば足りる。
- 住民は一人ひとりが家・職場・店・学校のあいだを実際に移動する。人や車、列車の動きはリアルタイムで計算する。
- 目標とする規模は Cities: Skylines II（以下 CS2）並みとする。人口 10 万人が快適に動き、100 万人まで伸ばせる設計にする。
- 遊び方はサンドボックスとする。終わりはなく、人口が増えると使える建物や政策が増えていく。

## 構成

| 部分 | 技術 | 役割 |
|---|---|---|
| シミュレーションの中核 | Rust | 街の状態を持ち、時間を進める。ブラウザでは WASM にして Web Worker で動かす |
| 画面と操作 | TypeScript、Canvas または WebGL | 中核から受け取った状態を描き、プレイヤーの操作を中核へ渡す |
| バックエンド | Go（今は作らない） | 街の保存・共有・他人の街への訪問を受け持つ |

- 中核は描画にも通信にも依存しない Rust のクレートにする。同じクレートをネイティブにビルドすれば、サーバーでも動かせる。
- 中核は決定論的に作る。同じ初期状態と同じ操作の列からは、どこで動かしても同じ結果になるようにする。
  - 乱数は種を固定した生成器だけを使う。
  - 座標や速度は固定小数点の整数で持ち、浮動小数点の環境差を避ける。
  - スレッドに分けて計算するときも、結果が実行順に左右されないようにする。
- 中核を複数スレッドで動かすには、ページが COOP/COEP ヘッダー付きで配信されている必要がある。配信先はこれを満たす場所を選ぶ。

## 地図

### 形式

- マス目（1 マス 8m 四方）を基本とし、道路と線路は 45 度の斜めも引ける。
- 地図はチャンク（64×64 マス、約 512m 四方）に分けて持ち、必要なチャンクだけをメモリに置く。
- 広さに上限は設けない。ワールド座標は 64 ビットで持つ。

### 地形

- 各マスに標高を持たせる。高低差は車の速度、建設費、歩く人の経路選びに影響する。
- 川や海などの水辺がある。
- 地形は、街の種とチャンク座標から手続き的に生成する。同じ種からは必ず同じ地形が生まれる。

### 土地の購入

- プレイヤーは買った土地にだけ建設できる。
- 人口のマイルストーンに届くと買える区画の枠が増え、隣のチャンクをお金を払って買える。CS2 と同じ仕組みにする。

### 層

地図を高さごとの層に分けて持つ。層は欠かせない要素だが、最初の版は地上だけで作り、地上、高架、地下の順に足していく。データの持ち方と経路探索は、最初から複数の層を前提にしておく。

| 層 | 置くもの | 入れる順 |
|---|---|---|
| 地上 | 道路、鉄道、建物、歩道 | 1（最初の版） |
| 高架 | 高架道路、高架鉄道 | 2 |
| 地下 | 地下鉄の線路と駅（将来は地下道） | 3 |

- 画面では層を切り替えられる。高架や地下を表示しているときは、地上を薄く透かして重ねる。
- 高架や地下の駅は、地上の出入口とホームを縦につなぐ。経路探索は層をまたいで行う。

### データレイヤー

- 地図の上に、数値を色で塗った面を重ねて表示する。それぞれ独立にオンとオフを切り替えられる。
- 標高は、標高帯ごとに色分けした面（段彩）と等高線で表す。
- 同じ仕組みで、汚染・騒音・地価・交通量・サービスの届く範囲なども表示する。
- データレイヤーは層の切り替えとは別系統で、自由に組み合わせられる。

### 外部接続

CS2 の外部接続にならい、広さに上限のない地図に合わせて次のように読み替える。

- 高速道路、幹線鉄道、航路、空路、送電線を「世界を走る幹線」として、地形と同じく種から手続き的に生成する。幹線は買った範囲の外へ続いていて、その先が「外の世界」になる。
- 開始地点には高速道路が来ていて、最初はそこにつないで街を始める。
- 買っていない土地の上の幹線も機能する。外部と行き来する車や列車はそこを通れる。
- 別の幹線の近くまで土地を広げると、そこへの接続を作れる。
- 外部接続を通じて移住者が来て、物の輸出入や電力の売り買いが行われる。
- 将来は、幹線の先を他人の街につなぐ入口にする。

## 建設

- 道路（大きさの違う数種類）、歩道、横断歩道、信号、鉄道、駅、バス停を置ける。高架と地下鉄は、それぞれの層を足すときに加える。
- 住宅・商業・工業・オフィスの区画を塗ると、需要に応じて建物が自然に建ち、育っていく。
- 公共施設（発電所、上下水道、ゴミ処理、病院、学校、警察、消防、公園など）はプレイヤーが自分で置く。

## 交通

地上を走る手段は次の 4 つにする。最初の版には徒歩と自家用車だけを入れ、バスと鉄道はその次に足す。地下鉄は地下の層を足すときに加える。

| 手段 | 走る場所 | 主な性質 |
|---|---|---|
| 徒歩 | 歩道 | 近い距離の移動や、駅・停留所までの移動に使う |
| 自家用車 | 道路 | 渋滞する。駐車場の問題が出る |
| バス | 道路 | 道路の上に路線を引く。渋滞に巻き込まれる |
| 鉄道 | 地上の線路 | 線路と駅を置いて路線を引く。ダイヤと定員がある |
| 地下鉄（後で足す） | 地下の線路 | 鉄道と同じ。地上の建物と干渉せずに引ける |

- 住民は移動のたびに、所要時間と費用を比べて手段と経路を選ぶ。複数の手段を乗り継いでもよい。

### 横断歩道と信号

- 歩行者は、近くに横断歩道があればそこを優先して道路を渡る。近くになければ、好きな場所で道路を横切る。
- 道路を横切る歩行者がいると車が止まるので、横断歩道の置き方が渋滞を左右する。
- 交差点には信号を置ける。信号は車と歩行者の進む順番を切り替える。

## 住民

住民の扱いを 2 層に分ける。

- **住民データ層**：全員が持つ。家、職場または学校、家族、所持金、幸福度、1 日の予定。ゲーム内の十数分に 1 回まとめて更新する。
- **移動層**：いま移動している人だけが持つ。家を出た時点で移動体になり、道路や線路の上を動く。着いたら消える。

## 幸福度

住民ごとに次の 4 つの点数を持ち、重みを付けて足し合わせたものを幸福度とする。重みは世帯の属性（子どもの有無、年齢、収入）で変える。

| 要素 | 中身 |
|---|---|
| 通勤・通学 | 家から職場や学校までの所要時間 |
| 生活サービス | 電気、水道、ゴミ収集、医療、教育、警察、消防がどれだけ届いているか |
| 環境 | 騒音、大気や土壌の汚染、公園や緑地 |
| 暮らし向き | 雇用、収入、家賃、税率、物価 |

## 財政

- 税収で建設費と維持費をまかなう。
- 税率は区画の種類ごとに決められる。
- 幸福度と財政のどちらを優先するかが、遊びの中心になる。

## 時間

- 等速では、ゲーム内の 1 日が約 24 分で進む。車や人の動きを目で追って、生活を眺められる速さにする。
- 一時停止ができ、速度は自由に変えられる。
- 最高速では 1 日を 5〜10 秒（144〜288 倍速）で回せるようにする。
- 速度に応じて、移動の計算の細かさを切り替える。

| 速度 | 移動の扱い |
|---|---|
| 等速〜1 日を約 1 分で回す速さ | 全員を移動体として動かす。車は車線を走り、信号で止まり、渋滞する |
| 中速（1 日を約 20 秒で回す速さまで） | 画面の外は区間ごとの所要時間だけを計算する。画面の中だけ 1 体ずつ動かす |
| 最高速 | 移動体を作らない。区間ごとの交通量から所要時間を見積もり、出発時刻に所要時間を足して到着させる |

- どの細かさで回しても、通勤時間・混雑・運賃収入などの数字が大きくずれないようにする。詳しい計算で測った区間ごとの所要時間を集計しておき、粗い計算ではその値を使う。

## 保存と共有

- 保存するのは、変更のあったチャンクと街全体の状態だけでよい。地形は種から作り直せる。
- 最初の版では、ブラウザの中に保存する。
- 将来は、Go のバックエンドで保存・共有・他人の街への訪問を扱う。決定論的な中核なので、操作の記録だけを送って相手の画面で街を再現する方式も選べる。

## 最初の版（MVP）

最初の版は地上の層だけで作る。交通は徒歩と自家用車に絞り、速度に応じて計算の細かさを切り替える仕組みを先に固める。CS2 並みの規模で動くかどうかは、この仕組みで決まるためである。

| 分野 | 入れるもの |
|---|---|
| 地図 | チャンクで区切った平らな地図、水辺、データレイヤーの仕組み、土地の購入 |
| 建設 | 道路（2〜3 種類）、歩道、横断歩道、信号、区画（住宅・商業・工業・オフィス） |
| 交通 | 徒歩、自家用車 |
| 生活インフラ | 電気、水道 |
| 住民 | 住民データ層と移動層 |
| 幸福度 | 通勤・通学、生活サービス（電気・水道）、暮らし向きの 3 つ |
| 財政 | 税収と維持費 |
| 時間 | 等速から最高速まで。速度に応じて計算の細かさを切り替える |
| 外部接続 | 高速道路 1 本 |
| 保存 | ブラウザの中 |

最初の版のあとに、次のものを足す。層は高架、地下の順に足すが、ほかの順番はまだ決めていない。

- 高低差と、標高の段彩表示
- バスと鉄道
- 環境の要素（騒音・汚染・公園）
- ゴミ処理、医療、教育、警察、消防
- 高架
- 地下と地下鉄

## まだ決めていないこと

- 経済の細かい仕組み（物の流れ、産業の種類、需要の計算）
- 公共施設の種類と、サービスがどう届くか（距離で届くか、車両が回るか）
- 政策と地区の仕組み
- 画面の操作体系（マウス、キーボードショートカット）
